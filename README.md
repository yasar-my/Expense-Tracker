# RoomLife — Personal Expense Tracker

A mobile-first React + Vite expense tracker for one person using one device.

## Features
- Dashboard with Room Rent, Travel, Food, Snacks and Grand Total
- Food breakdown: Breakfast, Lunch, Dinner
- Date-based expense records
- Add / Edit / Delete individual expenses
- Delete all data with confirmation
- Data persists in browser LocalStorage
- Responsive mobile, tablet, laptop and desktop UI
- No login and no backend required

## Run
```bash
npm install
npm run dev
```

Open the local Vite URL in your browser.

## Storage
All expense data is stored in LocalStorage under:
`roomlife-expenses-v1`

Clearing browser site data will remove the stored expenses.
